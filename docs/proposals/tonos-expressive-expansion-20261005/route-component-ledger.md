# Tonos route and component ledger — 2026-10-05

## Scope and method

Read-only audit of the current working tree on `feature/classic-m3e`, starting HEAD `ab18ed8cab5582c8449e13724afae3c4b74ebeea`. The tree already contains extensive source, test, and proposal changes. No source or test files were changed for this ledger; tests/builds were not run during this audit. Ratings describe source treatment and current candidate status, not approval of an unapproved family.

Reachability was traced from `lib/main.dart` (`MaterialApp.home`, named routes, `MainScreen._pageForTab`) and `lib/providers/nav_bar_config.dart`, then through production `Navigator` callers in the owning pages. The route tests (`test/theme/e2_route_ledger_contract_test.dart`, `b6_route_evidence_test.dart`, `pre_q2_route_evidence_test.dart`) were used as corroboration, not as the sole route source.

### Navigation and counting

`MainScreen` registers 11 tab destinations. Five are enabled on first install: Train, Catalog, Logbook, Progress, Profile. Dashboard, Nutrition, and Train2 are release-capable but default-off and can be enabled in Navigation Editor. Nutrition Log, Combined History, and Form and Posing are experimental; `NavigationBuildPolicy` denies them in release. `/main` is the production named route. Theme Lab home selection and `/__theme_lab` are debug-only.

For comparison with the current review inventory, the normalized count is 55 distinct page archetypes in the configurable/non-release source graph and 52 when the three release-denied tab destinations are excluded. Dialogs, sheets, overlays, media viewers, and shared boundaries are states/components, not extra page archetypes. Default-off does not mean unreachable: Dashboard, Nutrition, and Train2 remain available to a release user through Navigation Editor. Nutrition's child routes require enabling the Nutrition tab first.

**Count caveat:** the current working-tree source also contains the separately reachable `MeasurementsTrendsSettingsPage` (`ProfilePage` → Progress Settings) and `AutoPresetFlowScreen` (Workout Progress Flows → editor). Both are listed below. Older route groupings do not make this overlap/counting boundary completely clear; treat 55/52 as the normalized inventory count, not a code-generated proof. The test-guarded E2 ledger has 65 evidence rows because it separately records shared dialog/sheet/media boundaries.
