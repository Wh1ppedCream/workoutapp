# Expressive Next Pages: Route and Review-State Ledger

This is a source-based inventory for choosing the next Expressive page batch. It records route reachability and review states; it does not qualify screenshots, approve design, or authorize changes outside the selected batch. No production Dart or tests were changed for this ledger.

## Snapshot, counting rule, and scope

- Checkout: `E:\projects\env_test`; audited source HEAD: `66aa899fc497eafed78268eae7ddce345b74b919` on `feature/classic-m3e`.
- Count: **55 unique production-reachable page archetypes**. Five default-enabled tabs + six default-off configurable tabs + one onboarding route + 15 other exercise/catalog/logbook routes + 17 settings routes + two detail routes defined in widgets + nine Nutrition subroutes.
- A page archetype is a distinct reachable page class. Shared pages count once even when reached from multiple callers. Dialogs, sheets, editors presented within a page, selections, empty/loading/error states, and onboarding wizard steps are review states, not additional page archetypes. The catalog’s purpose-built Exercise Details sheet is therefore excluded from this page-only count even though the existing 25-entry dossier counts it as a candidate archetype.
- Status labels: **Already Expressive / frozen** = deliberate treatment exists but is protected; **Partial** = only some callers/components or modes receive deliberate treatment; **Classic/Neo-only** = reachable but no deliberate Expressive treatment found; **Candidate** = eligible route for this expansion; **Blocked / protected** = explicitly frozen or materially overlaps frozen work; **Placeholder** = reachable but has placeholder content; **Out of scope** = default-off/paused feature family excluded from this expansion.
- “Review states” below are route-specific states to cover if a route enters review. They are not claims that each state has current visual evidence. Before any edit, compare against the live working tree; dirty/untracked status is called out explicitly.
- The selected review batch is **Plan Management, Premade Plans, Preset Detail, Optimized Workout Settings, and Gym Profile**. These five route owners now contain isolated Expressive-preview presentation branches with route tests and Pixel 7 captures. The work remains unapproved and is not a rollout decision.
