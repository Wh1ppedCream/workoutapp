Delete Your Tonos Data

Last updated: August 9, 2026

Tonos is local-first and does not require an account. Most information is therefore deleted directly from the device where you use the app.

Sync Diagnostic History

Open Profile > Diagnostics & Privacy and choose Clear sync history. This removes the capped list of content-sync outcomes stored on the device. Current production builds do not submit remote crash reports.

Local Database and Preferences

Clear Tonos storage from the operating system's app settings, or uninstall Tonos. This removes the local workout, nutrition, body metric, profile, preference, and diagnostic data held by that installation. Uninstalling does not remove files that you exported to another location.

Exported Backups and Cached Media

Delete exported database backups using the file manager or storage provider where you saved them. Downloaded public media can be removed from Database Settings with Clear Downloaded Media Cache, or by clearing all Tonos app storage.

Earlier Validation Crash Reports

Current production builds do not send crash reports. If you explicitly opted in while using an earlier validation build and want a submitted Sentry report removed, contact the developer with its event time, app version, device platform, and any event identifier available to you. This information helps locate the report without requesting identity or health data. Earlier validation reports are automatically deleted after no more than 90 days and may be deleted sooner under the service plan.

Contact

Submit a privacy or deletion request through the Tonos project page. Do not include health information or a database backup in a public issue.
