# Historical Roadmaps

The files in this directory are preserved snapshots of the three root-level
roadmaps last maintained in 2025. They describe an earlier application
structure and contain many tasks that are now complete, renamed, or explicitly
deferred.

Use `../../maintenance-backlog.md` for current product and engineering
priorities. Use `../../cloud-content-roadmap.md` and the associated content
playbook for media publishing work.

The original filenames are intentionally retained so old references and commit
history remain understandable:

- `roadmap.txt`
- `roadmap immediate.txt`
- `roadmap seperated.txt` (original spelling retained)
