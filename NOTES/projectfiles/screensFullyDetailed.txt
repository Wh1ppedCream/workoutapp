**6.2 State & Initialization**

* **Props:** `final WorkoutSession session;`
* **State Fields:**

  * `List<WorkoutExercise> _exercises = []`
  * `bool _isEditing = false;`
  * `bool _hasChanges = false;`
  * `DateFormat _dateFmt;`
* **initState():**

  * Initialize `_dateFmt = DateFormat('MMM dd • HH:mm');`
  * Call `_loadExercises()` then schedule `SessionCompleteSheet` via `WidgetsBinding.instance.addPostFrameCallback`.

**6.3 Data Loading**

```dart
Future<void> _loadExercises() async {
  final repo = AppRepository();
  final rows = await repo.fetchExercises(session.id);
  List<WorkoutExercise> loaded = [];
  for (var row in rows) {
    if (row.type == ExerciseType.weight) {
      // Fetch sets & changeSets...
      loaded.add(WeightExercise(...));
    } else if (row.type == ExerciseType.cardio) {
      loaded.add(CardioExercise(...));
    } else if (row.type == ExerciseType.stretch) {
      loaded.add(StretchExercise(...));
    }
  }
  setState(() { _exercises = loaded; _hasChanges = false; });
}
```

**6.4 UI & Interaction**

```dart
@override
Widget build(BuildContext context) {
  return WillPopScope(
    onWillPop: () async {
      if (_hasChanges) return await _showDiscardDialog();
      return true;
    },
    child: Scaffold(
      appBar: AppBar(
        title: Text(_dateFmt.format(session.date)),
        actions: [
          IconButton(icon: Icon(_isEditing ? Icons.check : Icons.edit), onPressed: () => setState(() => _isEditing = !_isEditing)),
          IconButton(icon: Icon(Icons.delete), onPressed: _deleteSession),
        ],
      ),
      body: _exercises.isEmpty
        ? Center(child: Text('No exercises logged.'))
        : ListView.builder(
          itemCount: _exercises.length,
          itemBuilder: (_, i) => ExerciseCard(
            exercise: _exercises[i],
            isEditing: _isEditing,
            onDelete: () { setState(() => _exercises.removeAt(i)); _hasChanges = true; },
            onValueChanged: () => _hasChanges = true,
          ),
        ),
      bottomNavigationBar: _hasChanges
        ? Padding(
            padding: EdgeInsets.all(8),
            child: ElevatedButton(onPressed: _saveChanges, child: Text('Save Changes')),
          )
        : null,
    ),
  );
}
```

## 7. Analytics Dashboard Screen

**File:** `lib/screens/exercise/analytics_dashboard_screen.dart`

**7.1 Imports & Internal Models**

```dart
import 'package:flutter/material.dart';
import '../repository/app_repository.dart';

class _ItemCount { final String name; final int count; _ItemCount(this.name, this.count); }
```

**7.2 State & Data Loading**

* **State Fields:** `_isLoading`, `_error`, `List<_ItemCount> _muscleCounts`, `_bodyPartCounts`
* **initState():** call `_loadData()`
* **\_loadData():**

  1. Query `repo.fetchSetsPerMuscle(start, end)`
  2. Query `repo.fetchSetsPerBodyPart(start, end)`
  3. Map IDs to names via `repo.fetchAllMuscles()` / `repo.fetchAllBodyParts()`
  4. Floor counts & filter zero, sort desc
  5. setState accordingly

**7.3 Build & Tabs**

```dart
@override
Widget build(BuildContext context) {
  return DefaultTabController(
    length: 2,
    child: Scaffold(
      appBar: AppBar(
        title: Text('Sets in Last 7 Days'),
        bottom: TabBar(tabs: [Tab(text:'By Muscle'), Tab(text:'By Body Part')]),
      ),
      body: _isLoading
        ? Center(child:CircularProgressIndicator())
        : _error != null
          ? Center(child: Text(_error!))
          : TabBarView(
              children: [
                _buildCountList(_muscleCounts),
                _buildCountList(_bodyPartCounts),
              ],
            ),
    ),
  );
}

Widget _buildCountList(List<_ItemCount> items) {
  if (items.isEmpty) return Center(child: Text('No data available.'));
  return ListView.builder(
    itemCount: items.length,
    itemBuilder: (_, i) => ListTile(title: Text(items[i].name), trailing: Text(items[i].count.toString())),
  );
}
```

**11.3 Filter Logic**

```dart
void _applyAllFilters() {
  var list = List<ExerciseDefinition>.from(_allDefs);
  if (_useProfileFilter) {
    list = list.where((d) => d.equipment.any((e) => profileEquipment.contains(e))).toList();
  }
  if (_selectedEquipment != null) list = list.where((d) => d.equipment.contains(_selectedEquipment)).toList();
  if (_selectedArea != null) list = list.where((d) => d.area == _selectedArea).toList();
  if (_selectedMuscle != null) list = list.where((d) => d.primaryMuscles.contains(_selectedMuscle)).toList();
  if (_searchQuery.isNotEmpty) list = list.where((d) => d.name.toLowerCase().contains(_searchQuery.toLowerCase())).toList();
  setState(() => _displayedDefs = list);
}
```

```dart
Future<void> _save() async {
```

### 31.4 Helper Methods

* **\_yValue(Measurement m):**
  Converts inches→feet for height when in ‘ft/in’ sub‑filter; otherwise returns raw value.
* **\_computeSpots(List<Measurement> data):**
  Maps measurements to `FlSpot(x, y)` according to `_timeFilter` (days for Weekly, day-of-month for Monthly, month index for Yearly, index order for All Records).
* **\_buildBottomTitles(…):**
  Returns `AxisTitles` for the chart’s X‑axis—weekday initials for Weekly, selected day ticks for Monthly, month letters for Yearly, or hidden for All Records.
* **\_applyFilters(List<Measurement> all):**
  Filters by time window, then by `_subFilter` (unless it's Height, which always shows all).

```dart
@override
Widget build(BuildContext context) {
  final name = widget.definition.name;

  return Scaffold(
    appBar: AppBar(title: Text(name)),
    body: FutureBuilder<List<Measurement>>(
      future: _measurementsFuture,
      builder: (ctx, snap) {
        if (snap.connectionState != ConnectionState.done) {
          return const Center(child: CircularProgressIndicator());
        }
        if (snap.hasError) {
          return Center(child: Text('Error: ${snap.error}'));
        }

        final all      = snap.data!;
        var filtered    = _applyFilters(all)..sort((a, b) => a.timestamp.compareTo(b.timestamp));
        final spots     = _computeSpots(filtered);
        final bottomTitles = _buildBottomTitles(filtered, spots);

        return Padding(
          padding: const EdgeInsets.all(16),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [

              // Time Filter Buttons
              Row(
                children: timeOptions.map((f) {
                  return Expanded(
                    child: Padding(
                      padding: const EdgeInsets.symmetric(horizontal: 1),
                      child: OutlinedButton(
                        style: OutlinedButton.styleFrom(
                          backgroundColor: _timeFilter == f ? Colors.deepPurple : null,
                          foregroundColor: _timeFilter == f ? Colors.white : null,

                        onPressed: () => setState(() => _timeFilter = f),

                    child: Padding(
                      padding: const EdgeInsets.symmetric(horizontal: 1),
                      child: OutlinedButton(
                        style: OutlinedButton.styleFrom(
                          backgroundColor: _subFilter == s ? Colors.deepPurple : null,
                          foregroundColor: _subFilter == s ? Colors.white : null,
                        ),
                        onPressed: () => setState(() => _subFilter = s),
                        child: Text(s),
                      ),
                    ),
                  );
                }).toList(),

              const SizedBox(height: 16),

              // Line Chart
              SizedBox(
                height: 200,
                child: LineChart(
                  LineChartData(
                    minX: spots.isEmpty ? 0 : spots.first.x,
                    maxX: spots.isEmpty ? 0 : spots.last.x,

                              ? '${(m.value~/12)}ft ${(m.value%12).toInt()}in'
                              : '${m.value.toStringAsFixed(1)} ${m.unit}';
                          return LineTooltipItem(
                            '$displayValue\n$date',
                            const TextStyle(color: Colors.white),
                          );
                        }).toList(),
                      ),
                    ),
                    lineBarsData: [LineChartBarData(spots: spots, isCurved: false, dotData: FlDotData(show: true))],
```

```dart
      _entries   = computed;
      _overrides = overrideIds;
    });

    if (!mounted) return;
```

### 40.4 Data Loading

```dart
Future<void> _loadLookups() async {
  try {
    final bps = await _repo.fetchAllBodyPartsFull();
    final ms  = await _repo.fetchAllMusclesFull();
    if (!mounted) return;
    setState(() {
      _bps = bps;
      _ms  = ms;
      _selBp = bps.isNotEmpty ? bps.first : null;
      _selM  = ms.isNotEmpty  ? ms.first  : null;
      _lookupError = null;
    });
    if (_selBp != null) await _loadBpBounds(_selBp!.id);
    if (_selM  != null) await _loadMBounds(_selM! .id);
  } catch (e) {
    if (!mounted) return;
    setState(() => _lookupError = e.toString());
  } finally {
    if (!mounted) return;
    setState(() => _isLoadingLookups = false);
  }
}
```

* Fetches and populates both BodyPart and Muscle lists.
* Initializes selection to first item in each list.
* Triggers loading of their respective volume boundaries.
