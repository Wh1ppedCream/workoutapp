main.dart

Purpose:Entry point of the Flutter app, configuring the app theme and main navigation via a BottomNavigationBar with four tabs: Train, History, Nutrition, and Profile.

Key components & flow:

main() & MyApp:

Initializes the app with runApp(MyApp()).

MyApp sets up MaterialApp with a seeded ColorScheme and uses MainScreen as the home.

MainScreen:

Stateful widget managing _selectedIndex for the bottom navigation.

Defines _pages list mapping indices to screen widgets: TrainPage, HistoryScreen, NutritionPage, and ProfilePage.

_onItemTapped updates the selected tab index.

BottomNavigationBar:

Renders four items with icons and labels.

Customizes colors: white background, deep purple selected, black54 unselected.

Observations & suggestions:

Routing vs tabs:

If future screens need deep linking, consider named routes or a navigation library (e.g., GoRouter).

State preservation:

Use IndexedStack instead of directly switching pages to preserve state when switching tabs.

Accessibility:

Add tooltip or semanticLabel for each BottomNavigationBarItem for screen reader users.

Theming consistency:

Align bottom bar colors with the app’s colorScheme rather than hard-coded values.

Testing:

Write widget tests verifying tab transitions and icon labels.

Performance:

Lazy load heavy screens (e.g., history with DB calls) only when first accessed rather than at startup.

import 'package:flutter/material.dart';
import 'screens/history_screen.dart';
import 'screens/train_page.dart';           // << Add this import
import 'screens/nutrition_page.dart';       // << And this
import 'screens/profile_page.dart';         // << And this

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({Key? key}) : super(key: key);

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Fitness Tracker',
      theme: ThemeData.from(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple),
      ),
      home: const MainScreen(),  // Use bottom navigation
    );
  }
}

class MainScreen extends StatefulWidget {
  const MainScreen({Key? key}) : super(key: key);

  @override
  _MainScreenState createState() => _MainScreenState();
}

class _MainScreenState extends State<MainScreen> {
  int _selectedIndex = 0;

  // List of pages for bottom navigation
  static final List<Widget> _pages = <Widget>[
    const TrainPage(),        // Train tab
    const HistoryScreen(),    // History tab
    const NutritionPage(),    // Nutrition tab
    const ProfilePage(),      // Profile tab
  ];

  void _onItemTapped(int index) {
    setState(() {
      _selectedIndex = index;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: _pages[_selectedIndex],
      bottomNavigationBar: BottomNavigationBar(
        // File: lib/main.dart
        // Customize colors for legibility
        backgroundColor: Colors.white,            // white background
        selectedItemColor: Colors.deepPurple,     // active icon/text color
        unselectedItemColor: Colors.black54,      // inactive icon/text color
        items: const <BottomNavigationBarItem>[
          BottomNavigationBarItem(
            icon: Icon(Icons.fitness_center),
            label: 'Train',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.history),
            label: 'History',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.restaurant),
            label: 'Nutrition',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.person),
            label: 'Profile',
          ),
        ],
        currentIndex: _selectedIndex,
        onTap: _onItemTapped,
      ),
    );
  }
}
