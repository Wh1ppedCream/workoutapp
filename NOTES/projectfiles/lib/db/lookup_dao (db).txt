lookup_dao.dart

Purpose:Provides lookup and CRUD operations for measurements, equipment, body parts, muscles, and stretches.

Key methods:

getMeasurementDefinitions(db):Retrieves all measurement definitions ordered by name as raw maps.

insertMeasurement(db, defId, ts, value, unit, note):Inserts a measurement record, converting DateTime to ISO-8601 string.

getMeasurementsForDefinition(db, defId):Fetches all measurements for a given definition, ordered by timestamp descending.

getUsedMeasurementDefinitions(db):Returns definitions that have at least one recorded measurement via a JOIN and GROUP BY.

getAllEquipmentNames(db):Retrieves a list of equipment names (List<String>).

getAllBodyParts(db):Retrieves all body parts as List<BodyPart> domain objects.

getStretches(db, [bodypartId]):Fetches stretches (as StretchDefinition objects) globally or filtered by a bodypartId, including associated bodyParts via additional queries.

getAllMuscleNames(db):Retrieves all muscle names (List<String>).

Observations & suggestions:

Batch query optimizations: The getStretches method issues N+1 queries—consider fetching stretch-bodypart joins in a single query and grouping client-side.

Typed return values: For methods returning raw maps, consider mapping to model classes (e.g., MeasurementDefinition) for type safety.

Error handling: Add try/catch blocks around database operations to log or handle failures gracefully.

Pagination & filtering: Provide optional parameters for limits, offsets, or additional filters to handle large datasets.

Cache static lookup lists: Since equipment, body parts, and muscles rarely change, cache these lists in memory after first load to reduce DB overhead.

DRY common patterns: Extract common mapping logic (e.g., map((r) => r['name'] as String)) into helper methods to reduce duplication


// File: lib/db/lookup_dao.dart

import 'package:sqflite/sqflite.dart';
import '../models/models.dart';

/// Encapsulates measurements, equipment/bodypart/muscle lookups, and stretches.
class LookupDao {
  /// Fetch all measurement definitions.
  static Future<List<Map<String, dynamic>>> getMeasurementDefinitions(
    Database db,
  ) {
    return db.query(
      'measurement_definitions',
      orderBy: 'name',
    );
  }

  /// Insert a new measurement instance.
  static Future<int> insertMeasurement(
    Database db,
    int defId,
    DateTime ts,
    double value,
    String unit,
    String? note,
  ) {
    return db.insert(
      'measurements',
      {
        'def_id':    defId,
        'timestamp': ts.toIso8601String(),
        'value':     value,
        'unit':      unit,
        'note':      note,
      },
    );
  }

  /// Fetch all measurements for a given definition.
  static Future<List<Map<String, dynamic>>> getMeasurementsForDefinition(
    Database db,
    int defId,
  ) {
    return db.query(
      'measurements',
      where: 'def_id = ?',
      whereArgs: [defId],
      orderBy: 'timestamp DESC',
    );
  }

  /// Returns only the definitions that have at least one measurement recorded.
  static Future<List<Map<String, dynamic>>> getUsedMeasurementDefinitions(
    Database db,
  ) {
    return db.rawQuery('''
      SELECT md.id, md.name, md.type 
        FROM measurement_definitions md
        JOIN measurements m ON m.def_id = md.id
       GROUP BY md.id
       ORDER BY md.name
    ''');
  }

  /// Fetch all equipment names.
  static Future<List<String>> getAllEquipmentNames(
    Database db,
  ) async {
    final rows = await db.query(
      'equipment',
      columns: ['name'],
      orderBy: 'name',
    );
    return rows.map((r) => r['name'] as String).toList();
  }

  /// Fetch all body-part IDs and names.
  static Future<List<BodyPart>> getAllBodyParts(
    Database db,
  ) async {
    final rows = await db.query(
      'bodypart',
      orderBy: 'name',
    );
    return rows
        .map((r) => BodyPart(r['id'] as int, r['name'] as String))
        .toList();
  }

  /// Fetch stretches by an optional bodypart ID (or all if null).
  static Future<List<StretchDefinition>> getStretches(
    Database db, [
    int? bodypartId,
  ]) async {
    final stretchRows = bodypartId == null
        ? await db.query('stretch_definitions', orderBy: 'name')
        : await db.rawQuery('''
            SELECT sd.id, sd.name, sd.description
              FROM stretch_definitions sd
              JOIN stretch_bodypart sb ON sb.stretch_id = sd.id
             WHERE sb.bodypart_id = ?
             ORDER BY sd.name
          ''', [bodypartId]);

    final List<StretchDefinition> result = [];
    for (final r in stretchRows) {
      final id   = r['id'] as int;
      final nm   = r['name'] as String;
      final desc = (r['description'] as String?) ?? '';

      final bpRows = await db.rawQuery('''
        SELECT b.id, b.name
          FROM bodypart b
          JOIN stretch_bodypart sb ON sb.bodypart_id = b.id
         WHERE sb.stretch_id = ?
         ORDER BY b.name
      ''', [id]);
      final bpList = bpRows
          .map((b) => BodyPart(b['id'] as int, b['name'] as String))
          .toList();

      result.add(StretchDefinition(
        id: id, name: nm, description: desc, bodyParts: bpList,
      ));
    }
    return result;
  }

  /// Fetch all muscle names.
  static Future<List<String>> getAllMuscleNames(
    Database db,
  ) async {
    final rows = await db.query(
      'muscles',
      columns: ['name'],
      orderBy: 'name',
    );
    return rows.map((r) => r['name'] as String).toList();
  }
}
