## QuickBar (`lib/widgets/quick_bar.dart`)

**Description:** A three‑segment quick‑action bar for adding measurements, logging food, or starting workouts.

**Class Signature:**

```dart
class QuickBar extends StatelessWidget {
  final double scale;
  const QuickBar({Key? key, this.scale = 1.0}) : super(key: key);
  @override
  Widget build(BuildContext context) => ...
}
```

**Properties:**

* `scale` (`double`): Uniform scale factor applied to padding, heights, border radii, and font sizes.

**Build Hierarchy:**

1. `Container` (margin: `EdgeInsets.symmetric(horizontal:16*scale, vertical:8*scale)`, shape: rounded via `BorderRadius.circular(24*scale)`)
2. `Row` of three `Expanded` children:

   * **Measurement Segment:**

     * `Container` (background: `Colors.teal.shade100`, left corner radius)
     * `InkWell` (borderRadius, onTap pushes `NewMeasurementItemPage()`)
     * `Padding` → `SizedBox(height:40*scale)` → `Center(Text('+ Measurement', style: fontSize12*scale, weight600, color: teal800))`
   * **Divider:** `Container(width:1*scale, height:40*scale, color: grey.shade400)`
   * **Food Segment:** similar, background `orange.shade100`, onTap pushes `FoodLoggingPage()`, label '+ Food', fontSize14\*scale.
   * **Divider** (same)
   * **Workout Segment:**

     * `Container` (background `green.shade100`, right corner radius)
     * `InkWell`: onTap calls `context.read<ActiveSession>().start()`, pushes `SessionScreen()`
     * Label '+ Workout', fontSize14\*scale, color green800.

**Interactions:**

* Navigations via `Navigator.of(context).push(...)`.
* Session start via Provider `ActiveSession`.

**Class Signature:**

```dart

```

**State:**

**Build Hierarchy:**

1. Compute `s = widget.scale`.
2. `detailWidgets` list of three:

   * `NutritionCircleDetails`(all values + `scale: s`)
   * `NutritionBarDetails`(all values + `scale: s`)
   * `NutritionTextDetails`(all values + `scale: s`)

   * `SizedBox(height:330*s)` → `PageView(onPageChanged: update _currentPage, children: detailWidgets)`.
   * `Row` of `AnimatedContainer` dots: size & color depend on `_currentPage`.
   * `MealPlanAddBar(scale: s)`.

## RoundedProgressIndicator (`lib/widgets/rounded_progress_indicator.dart`)

**Description:** Donut‑style progress indicator with rounded ends.

**Class Signature:**

```dart
class RoundedProgressIndicator extends StatelessWidget {
  final double progress; // 0.0–1.0
  final double size;
  final Color progressColor, backgroundColor;
  final double strokeWidth, scale;
  const RoundedProgressIndicator({ ..., this.strokeWidth=12, this.scale=1.0 });
  @override Widget build(BuildContext context) => ...;
}
```

**Build Hierarchy:**

* Compute `actualSize = size*scale`, `actualStroke = strokeWidth*scale`.
* `SizedBox(width:actualSize, height:actualSize)` → `CustomPaint(painter: _RoundedProgressPainter(...))`.

**Painter (`_RoundedProgressPainter`):**

* **paint(Canvas, Size):**

  * Determine `center`, `radius = (min(width,height) - strokeWidth) / 2`.
  * Draw full circle track with `backgroundColor`.
  * Draw arc from `-pi/2` over `2*pi*progress` with `progressColor`, `strokeCap.round`.
* **shouldRepaint:** returns `true` if any parameter changed.

**State Variables:**

**Build Hierarchy:**

   * **Profile Selector:** `Padding` → `DropdownButtonFormField<String>`:

     * `value = sel.currentProfile?.name`

## PresetBar (`lib/widgets/preset_bar.dart`)

**Description:** Colored bar representing a workout preset, with context menu and auto badge.

**Class Signature:**

```dart
class PresetBar extends StatelessWidget {
  final int presetId, index;
  final String label;
  final Color color;
  final bool isAutomatic;
  final VoidCallback onRefresh;
  final double scale;
  const PresetBar({Key? key, required this.presetId, required this.label, required this.color, required this.index, this.isAutomatic=false, required this.onRefresh, this.scale=1.0}) : super(key: key);
  @override Widget build(BuildContext context) => ...;
}
```

**Build Hierarchy:**

* `GenericBar` (background `color`, `scale`):

  * `label`: trimmed or default 'Preset \${index+1}'.
  * `onTap`: pushes `PresetDetailScreen` wrapped in `MultiProvider` for `ActiveSession` & new `PresetSession(presetId)`.
  * `trailing`: `Row` including optional `_AutomaticBadge(scale)` and `PopupMenuButton<String>`:

    * Icon size `24*scale`, color `color`.
    * Menu items: Edit, Delete, Rename.

**Menu Actions:**

* **Edit:** calls `_openDetail(context)`.
* **Delete:** confirmation dialog, onYes calls `repo.deletePreset(presetId)` then `onRefresh()`.
* **Rename:** input dialog with `TextEditingController`, onConfirm calls `repo.updatePresetName(presetId, newName)` then `onRefresh()`.

## PastSessionsList (`lib/widgets/past_sessions_list.dart`)

**Description:** Card containing a filterable, scrollable list of past workout sessions.

**Class Signature:**

```dart
class PastSessionsList extends StatefulWidget {
  final VoidCallback? onReload;
  final double height;
  const PastSessionsList({Key? key, this.onReload, this.height = 300}) : super(key: key);
  @override State<PastSessionsList> createState() => _PastSessionsListState();
}
```

**State Variables:**

* `_options`: Map\<String,int?> for filters ('Week':7, 'Month':30, 'Year':365, 'All'\:null).
* `_selected`: current filter key.
* `_sessionsFuture`: Future\<List<WorkoutSession>>.
* `_repo = AppRepository()`.

**Lifecycle:**

* `initState()`: calls `_loadSessions()`.
* `_loadSessions()`: computes `start = now.subtract(Duration(days: days))` or fetch all, sets `_sessionsFuture` and calls `setState()`.

**Build Hierarchy:**

* `SizedBox(height: widget.height)` → `Card(margin vertical8)` → `Padding(all:12)` → `Column`:

  * **Header Row:**

    * `Text('Show:')`, `DropdownButton(value:_selected, items:_options.keys...)`, `Spacer()`, `IconButton(Icons.fullscreen, onPressed push FullHistoryScreen)`.
  * **Expanded** → `FutureBuilder<List<WorkoutSession>>(future:_sessionsFuture)`:

    * `ConnectionState.waiting`: `CircularProgressIndicator()`.
    * `hasError`: `Text('Error: ${snap.error}')`.
    * Data empty: `Text('No sessions yet.')`.
    * Data present: `ListView.separated(itemCount:sessions.length)`:

      * For each session:

        * Format `dateStr = DateFormat('yyyy-MM-dd').format(ses.date)`.
        * Compute `durationMin = (ses.duration/60).ceil()`.
        * `Card(margin: horizontal2, vertical4)` → `ListTile(title: Text('$dateStr — $durationMin min'), onTap: push SessionDetailScreen(ses).then(() => {widget.onReload?.call(); _loadSessions();}))`.

## SessionCompleteSheet (`lib/widgets/session_complete_sheet.dart`)

**Description:** Draggable bottom sheet summarizing a completed session.

**Class Signature:**

```dart
class SessionCompleteSheet extends StatelessWidget {
  final int sessionId;
  const SessionCompleteSheet({Key? key, required this.sessionId}) : super(key: key);
  @override Widget build(BuildContext context) => ...;
}
```

**Helpers:**

* **`_SessionData`** container holding `WorkoutSession` and `List<WorkoutExercise>`.
* **`_loadData(repo)`**: async fetch session and detailed exercises.

**Build Hierarchy:**

* `FutureBuilder<_SessionData>(future:_loadData(repo))`:

  * Loading/Error: `SizedBox(height:200, child: Center(CircularProgressIndicator() or Text('Error')))`.
  * Data ready: call `_buildContent(context, data)`.

### `_buildContent`

* Compute `totalVol` by summing `weight*reps` for each `WeightExercise` and its sets.

* Format `dateStr = DateFormat('MMM dd • HH:mm').format(session.date)`.

* Format `durStr` from `session.duration` seconds into `HH:mm:ss`.

* Hardcode `calories = 100`, `gymScore = '5/10'` (placeholders).

* `DraggableScrollableSheet(expand:false, initialChildSize:0.5, maxChildSize:0.95)` → `Stack`:

  1. **Column:**

     * **Header:** `Padding(all:16)` → `Column`:

       * Text 'SESSION COMPLETE!' styled
       * Row(dateStr, 'Duration: durStr')
       * Text('Volume: totalVol lbs • Calories: 100 kcal')
       * Text('Gym Score: 5/10')
     * `Divider()`
     * **Expanded** → `ListView.builder(controller:scrollCtrl, padding horizontal16 vertical8)`:

       * For each exercise:

         * `WeightExercise`: call `_buildWeightSection(ex)`
         * `CardioExercise`: `ListTile(leading Icon(Icons.fitness_center), title Text('${ex.cardioName} • ${minutes} min'))`
         * `StretchExercise`: `ListTile(leading Icon(Icons.self_improvement), title Text(ex.name))`
  2. **Positioned** bottom-right: `FloatingActionButton` (green, icon `Icons.check`, onPressed pop).

### `_buildWeightSection`

* Header `Text('■ ${ex.name}')`
* For each set:

  * Row(text '\${i+1}. weight lbs × reps', Spacer(), Text('ERM=...', italic, fontSize12)).

**Class Signature:**

```dart

  final StretchExercise exercise;
  final bool readOnlyMode;
  final VoidCallback? onDeleteExercise;
  final VoidCallback? onValueChanged;
  const StretchCard({Key? key, required this.exercise, this.readOnlyMode=false, this.onDeleteExercise, this.onValueChanged}) : super(key: key);

```

**State Variables:**

* `_stretchCustomController`: `TextEditingController` for custom name input.
* `_completedStretches`: `Set<int>` of checked instance indices.

**initState():**

* Initialize `_stretchCustomController`.
* Seed `_completedStretches` by iterating `exercise.stretchInstances`.

**build(context):**

  1. **Header Row:**

     * `Text(exercise.name)` with `titleMedium` style.

     * `ElevatedButton.icon(Icons.search)` → calls `StretchSearchDialog.show`, on chosen adds to `stretchList` and marks checked.

## WeightCard (`lib/widgets/weight_card.dart`)

**Description:** Card for editing weight exercises, sets, and optional change sets.

**Class Signature:**

```dart
class WeightCard extends StatefulWidget {
  final WeightExercise exercise;
  final bool readOnlyMode;
  final Set<int>? initialCompletedParents;
  final Map<int,Set<int>>? initialCompletedChildren;
  final VoidCallback? onDeleteExercise;
  final VoidCallback? onSetAdded;
  final VoidCallback? onSetDeleted;
  final VoidCallback? onValueChanged;
  final VoidCallback? onDetails;
  const WeightCard({Key? key, required this.exercise, this.readOnlyMode=false, this.initialCompletedParents, this.initialCompletedChildren, this.onDeleteExercise, this.onSetAdded, this.onSetDeleted, this.onValueChanged, this.onDetails}) : super(key: key);
  @override State<WeightCard> createState() => _WeightCardState();
}
```

**State Variables:**

* `_note` (`String`): equipment/note text.
* `_isEditingNote` (`bool`).
* `_weightControllers`, `_repsControllers`: lists of `TextEditingController` per parent set.
* `_isChangeSetMode` (`bool`): whether CSet UI is shown.
* `_cSets`: `Map<int,List<ExerciseSet>>` of change sets.
* `_completedSets`: `Set<int>` of checked parent sets.

**initState():**

* Seed `_note` from `exercise.equipment`.
* Initialize controllers for each `exercise.sets` entry.
* Populate `_completedSets` from `initialCompletedParents` or `exercise.completedParents`.
* Populate `_cSets` from `exercise.changeSets` and enable `_isChangeSetMode` if any.

**dispose():**

* Dispose all controllers.

**Methods:**

* `_updateWeightSet(int index)`: parse controllers, update `exercise.sets[index]`, call `onValueChanged()`.

**build(context):**

* `Card -> Padding -> Column`:

  1. **Header Row:**

     * `Text(exercise.name, style:titleMedium)`.
     * If `_isEditingNote`: `TextFormField(initialValue:_note)`, onSubmit updates `_note` and toggles off edit.
     * Else: `GestureDetector` wraps `Text(_note.isNotEmpty?_note:'Tap to add note')` toggles edit on tap.
     * `IconButton(icon:Icons.info_outline)` calls `widget.onDetails`.
     * `PopupMenuButton` ('Remove Exercise', 'Make ChangeSet') toggles `_isChangeSetMode` or calls `onDeleteExercise`.
  2. `Divider(height:16)`.
  3. **Parent Sets List:** generate for each index:

     * `Container` (border if changeSetMode) → `Row`:

       * `Checkbox(value:_completedSets.contains(idx))`, onChanged updates `_completedSets` and `exercise.completedParents`.
       * `Expanded(Text('Set ${idx+1}'))`.
       * `TextFormField(controller:_weightControllers[idx], label:'Weight')`, `onChanged`: `_updateWeightSet(idx)`.
       * `TextFormField(controller:_repsControllers[idx], label:'Reps')`, `onChanged`: `_updateWeightSet(idx)`.
       * `IconButton(Icons.remove_circle_outline)` confirmation, remove set, dispose controllers, call `onSetDeleted`.
  4. **ChangeSets UI:** if enabled/available:

     * For each CSet in `_cSets[idx]`, render scaled-down `Container` with fields for weight/reps and remove button.
     * "Add CSet" button: clones last parent set into `_cSets[idx]` and updates `exercise.changeSets`, calls `onValueChanged`.
  5. **Add Set Button:** `TextButton.icon(Icons.add, label:'Add Set')`, duplicates last set and controllers, calls `onSetAdded`.

**Callbacks:** all data mutations trigger the appropriate widget callbacks for external state updates.
