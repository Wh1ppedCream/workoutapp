Automatic Preset:
	- same as normal preset, but weighted exercises (no difference for stretches or cardio) will have their weight and/or reps updated automatically after every time the start session button is pressed for this preset on the preset detail page
	- option to not increment 1st set in exercise (selected by default)
	- customizeable increment amount(IA) default for full preset, used if individual exercise (IA) not set. 
			- customizeable increment amount(IA) for each exercise in preset
	- increments 1 set for each weighted exercise by (IA)
		- if failed to do increment amount in next session, reduces changed set by 2xIA and adds a rep to set
			- if failed agian, reduces set by 1 rep, keeps weight same
			- if succeded, +2xIA and -rep to set
		- if succeded, repeat for next set, till last set, if last set done, then repeat from 1st or 2nd set.

4. The Auto-Increment Algorithm
For each weight exercise in the preset (in order):
Choose target set index
If skip_first_set = true, start at set #2; else set #1.
Remember the last-used index, so on each successive auto-update we rotate through the sets.
Determine increment (IA)
If exercise has increment_amount override, use that; else use global_increment.
Compare last session’s performance on that set:
Success if they hit OR EXCEED target weight and reps.
Failure otherwise.
Adjust weight/reps:
On first Success:
weight += IA
reps will be same
On first Failure:
weight –= 2 × IA
reps will be same
If they fail again on that same set (i.e. weight or reps still unmet):
weight unchanged
reps = reps – 1
Advance to next set (wrapping around when you hit the last).
